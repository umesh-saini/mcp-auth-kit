# Security policy

`mcp-oauth-starter` is an authentication library, so security reports are the most valuable issues you can send.

**Please do not open a public issue for vulnerabilities.** Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include the affected version, a description of the issue, and steps or a test that reproduces it. You can expect a first answer within 72 hours. Fixes are released as patch versions and credited in the changelog, unless you prefer not to be named.

Supported versions: the latest minor release.
